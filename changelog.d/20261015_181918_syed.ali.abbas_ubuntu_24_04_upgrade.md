- 💥[Feature] Update Open edX Image to use Ubuntu 24.04 as base OS. (by @Syed-Ali-Abbas-568)
  - You will need to rebuild your `openedx` image (`tutor images build openedx`).
  - If you maintain a plugin or custom patch that runs `apt install` inside the openedx Dockerfile, check your package names against Ubuntu 24.04 (noble): several libraries were renamed with a `t64` suffix as part of Ubuntu's 64-bit `time_t` transition, and some other packages were renamed outright (e.g. `libicu70` → `libicu74`).
